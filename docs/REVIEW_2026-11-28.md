## Batch B. Security and abuse

| # | Problem | Where | Fix |
|---|---|---|---|
| B1 ✔ | The 3-farmer minimum is applied only in the browser. Any signed-in user, guests included, can read reports from one or two farmers (crop, disease, day, sale price) and time them by `updatedAt`. | `firestore.rules:772-776`, `_shared/area-store.ts:173-196` | Publish only groups with 3 or more farmers, with counts but not per-farmer days or prices. Keep raw data private, and round `updatedAt` to the day. |
| B2 | Three verified throwaway accounts can fake an outbreak. Free text in `diseaseKey` is copied into the push sent to everyone in the area. The daily quota check is not atomic. | `area-report.ts:39-83`, `_shared/area-model.ts`, `_shared/area-store.ts:141-154` | Accept only known crops, diseases and upazilas. Require a matching recent diagnosis. Build push text from known keys only. Use a transaction for the quota. |
| B3 | A farmer can write `verified:true` on a prescription and appear as "SAAO certified" in admin. | `firestore.rules:202-227` | On create require `verified == false` and `hasOnly`. Only admins may set the verification fields. |
| B4 | CSV export in admin is open to formula injection. | `AdminDashboard.tsx:615-618` | Prefix cells that start with `= + - @` with a quote. |
| B5 | Any user can flood an area's push list. Only 500 entries are read, so real farmers may be skipped. | `firestore.rules:805-823`, `_shared/push-send.ts:90-114` | Cap subscriptions per user, refuse guests, and page through all subscriptions. |
| B6 | The Live video token locks only the model. A caller can set their own instructions and safety settings. The token function returns raw errors. | `_shared/live-token.ts:108-119`, `gemini-live-token.ts:111-118` | Lock the system instruction and tools; return a generic error. |
| B7 | `link-preview` is an open fetch relay, and its SSRF check can be beaten by DNS rebinding. | `_shared/safe-url.ts:121-170`, `link-preview.ts` | Pin the checked IP, require sign-in, add a per-IP limit. |
| B8 | Several open functions have no limit and pass query text straight into upstream URLs. They can be called directly at `/.netlify/functions/<name>`, which skips the `/api` rate limits. | `daily-forecast`, `historical-data`, `loc-lookup`, `wb-indicators`, `soil-properties`, `ip-location`, `link-preview` | Validate and encode inputs, add per-IP limits, and use `config.path` / rate limit on each function. |
| B9 | Changing `timezone` on the paid Google weather endpoint skips the cache. The server can fall back to the browser `VITE_` key. | `weathernext-3.ts:85-131` | Allow only known values; use a server-only key. |
| B10 | Anyone who can verify an email gets the free AI allowance. There is no App Check. | `_shared/auth.ts:40-50`, `usage-quota.ts` | Turn on Firebase App Check and add a global daily spend cut-off. |
| B11 | The `test` collection is readable by anyone. Several collections accept extra fields and very large documents. Experts can still list and update consultations after consent expires. | `firestore.rules:668`, `:59-91`, `:391-442`, `:561-604` | Delete the `test` rule, add `hasOnly` and size limits, and check expiry in list and update. |
| B12 | The farm record score is built from values the farmer writes, so anyone can reach 100. | `record-facts.ts`, rules for diagnoses and seasons | Stamp time on the server and bound dates. Label the score "self-reported" wherever others see it. |

## Batch D. Simple-mode polish

- **Crop-doctor result:** add `ListenButton` to the answer. The officer/16123 line is the smallest text on the screen (11px); raise it to 14px or more. Drop uppercase and letter-spacing in Bangla.
- **Listen when no Bangla voice is installed:** check for a Bangla voice and say how to install one, or use AI speech.
- **English text in Bangla mode:** live-video and GPS errors; the "No safe window" string; `'User'` and the date on Profile.
- **Bangla numerals:** photo counter, candidate scores, dose results, dossier counts.
- **Fake ID when signed out:** FarmerDossier shows "BD-KRISHI-GUEST_FA".
- **Small text:** Experts, Profile and dossier still use 10–12px text in Simple mode.
- **Scheme chat:** add an "AI answer, confirm at the office" line and Listen; the close button needs a label.
- **Errors:** crop-doctor failures show only a toast; offline taps do nothing; Home weather has no "as of" time.
- **Slow start for returning users:** the app waits for Firestore before showing Home. Show Home once the user is known.
- **Smaller bugs:**
  - A failed "Done" on a task is not undone.
  - "Copied" shows even when copying failed.
  - The word ফরিয়াদের should be ফড়িয়ার.
  - A cost added while the list loads is lost.
  - `editingId` is not reset on sign-in.
  - Overdue tasks get no push.
  - Recovery notes take the UTC date between midnight and 6 AM.
  - The AI queue can leak slots when a request is aborted.
  - Plans past 20 are silently dropped.
